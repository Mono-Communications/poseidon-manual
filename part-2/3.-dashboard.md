# 3. 대시보드

`/dashboard` — 로그인 직후 나오는 화면. **전 고객사·전 서비스의 현재 상태를 한눈에** 봅니다. 아침 업무 시작 시 가장 먼저 확인하는 화면입니다.

부제: *운영 중인 인스턴스 한눈에 · 자동 갱신* / 기본 **30초** 자동 갱신.

├──────────────┬──────────────┬──────────────┬────────────────────────┤
│ ▤ 전체 인스턴스│ ✓ 실행 중     │ ✕ 종료        │ ⚠ 24H 이벤트            │
│      12      │      10      │      2       │      37                │
│ ODYSSEY 7 ·  │  전체의 83%   │  2대 응답 없음 │  최근 24시간             │

├───────────────────────────┬──────────────────────────────────────────┤

## 상단 KPI 카드 4개 — 전부 클릭됩니다

| 카드 | 숫자 | 보조 문구 | 클릭하면 |
| --- | --- | --- | --- |
| **전체 인스턴스** | 등록된 전체 대수 | `ODYSSEY 7 · TWOWAY 3 · CS 2` | [4. 인스턴스](4.-instances.md) 목록 |
| **실행 중** | `UP` 대수 | `전체의 83%` | 인스턴스 목록 (**UP만 필터**) |
| **종료** | `DOWN` 대수 | `2대 응답 없음` / 없으면 `없음` | 인스턴스 목록 (**DOWN만 필터**) |
| **24H 이벤트** | 최근 24시간 이벤트 수 | `최근 24시간` | [5. 이벤트](5.-events.md) |

{% hint style="info" %}
**"종료"는 `DOWN`의 화면 표기입니다.** 고객이 정상 종료한 경우와 신호가 끊긴 경우가 **같은 숫자에 섞여 있습니다.** 어느 쪽인지는 [5. 이벤트](5.-events.md)에서 `서비스 종료`(정상)인지 `하트비트 타임아웃`(비정상)인지로 구분합니다.
{% endhint %}

{% hint style="warning" %}
보조 문구의 서비스 내역에는 **`ODYSSEY` / `TWOWAY` / `CS` 세 종류만 표시됩니다.** `M2X` 인스턴스는 전체 대수에는 포함되지만 이 줄에는 나오지 않습니다. M2X 보유 고객사는 아래 "고객사별 인스턴스"에서 확인하십시오.
{% endhint %}

## 서비스별 헬스

서비스 타입별로 도넛 하나씩. 전체에서 차지하는 비중과 UP 비율을 봅니다.

| 표시 | 의미 |
| --- | --- |
| 칩 (`ODYSSEY` 등) | 서비스 타입 |
| `전체의 58%` | 전체 인스턴스 중 이 서비스의 비중 |
| 도넛 안 숫자 | 이 서비스의 인스턴스 수 |
| 도넛 채워진 비율 | 이 서비스 중 **UP 비율** |
| `▲ UP 7` / `▼ DOWN 0` | 실제 대수 |

인스턴스가 하나도 없으면 `등록된 인스턴스가 없습니다`가 나옵니다.

## 고객사별 인스턴스

**DOWN이 있는 고객사가 맨 위로** 정렬됩니다. 그다음은 보유 대수 순.

| 표시 | 의미 |
| --- | --- |
| 고객사명 + 회색 칩 | 고객사명과 **고객사 키** |
| `3대 · UP 2 · DOWN 1` | 대수 요약 |
| 초록/빨강 막대 | UP : DOWN 비율 |

행을 **펼치면** 그 고객사의 인스턴스가 칩으로 나오고, 칩을 클릭하면 **인스턴스 상세**로 바로 갑니다.

{% hint style="success" %}
장애 문의를 받았을 때 **가장 빠른 경로**입니다. 고객사명으로 찾아 → 펼쳐서 → 빨간 점 찍힌 인스턴스 클릭 → 바로 상세 화면.
{% endhint %}

## 최근 이벤트

최근 **20건**만 표시합니다. `전체 보기 →` 를 누르면 [5. 이벤트](5.-events.md) 화면으로 갑니다.

시간대별로 묶여 나옵니다: `방금 전`(30분 내) → `오늘 오전` → `오늘 오후` → `어제` → `이번 주` → `이전`.

각 줄을 클릭하면 해당 **인스턴스 상세**로 이동합니다.

이벤트가 없으면 `최근 24시간 이벤트가 없습니다`가 표시됩니다.
