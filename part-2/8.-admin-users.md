# 8. 사용자 (ADMIN)

<mark style="color:red;">**`/admin-users`**</mark> — **우리 팀 운영자 계정**을 승인·관리하는 화면입니다. 고객사 계정이 아니라 **Poseidon Ops에 로그인하는 내부 계정**입니다.

{% hint style="danger" %}
**ADMIN 전용입니다.** USER에게도 사이드바 메뉴는 보이지만 클릭하면 무응답입니다.
{% endhint %}

자동 갱신이 없습니다. **`새로고침`** 버튼을 쓰고, 승인·잠금 등 작업 후에는 자동으로 다시 조회됩니다.

### <mark style="color:purple;">상단 4칸 — 클릭시 필터</mark>

| 칸                | 대상                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------- |
| **전체 사용자**       | 필터 해제                                                                                    |
| **활성 (ACTIVE)**  | 정상 사용 중인 계정                                                                              |
| **대기 (PENDING)** | 가입 승인 대기                                                                                 |
| **잠금 / 거절**      | <mark style="color:red;">`SUSPENDED`</mark> + <mark style="color:red;">`REJECTED`</mark> |

| **아이디**  | 로그인 ID                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **이름**   | 가입 시 입력한 실명                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| **이메일**  | 가입 이메일                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **전화번호** | 가입 전화번호                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **상태**   | <mark style="color:red;">`PENDING`</mark> <mark style="color:red;"></mark><mark style="color:red;">/</mark> <mark style="color:red;"></mark><mark style="color:red;">`ACTIVE`</mark> <mark style="color:red;"></mark><mark style="color:red;">/</mark> <mark style="color:red;"></mark><mark style="color:red;">`SUSPENDED`</mark> <mark style="color:red;"></mark><mark style="color:red;">/</mark> <mark style="color:red;"></mark><mark style="color:red;">`REJECTED`</mark> |

## <mark style="color:blue;">계정 상태 4가지</mark>

***

| 상태              | 의미         | 로그인              |
| --------------- | ---------- | ---------------- |
| **`PENDING`**   | 가입했으나 승인 전 | ❌ (팝업 `승인 대기 중`) |
| **`ACTIVE`**    | 정상 사용 중    | ✅                |
| **`SUSPENDED`** | 잠김         | ❌ (팝업 `계정 잠금`)   |
| **`REJECTED`**  | 가입 거절됨     | ❌ (팝업 `승인 거절`)   |

## <mark style="color:blue;">상태별 작업 버튼</mark>

***

| 현재 상태           | 버튼     | 결과                                                              |
| --------------- | ------ | --------------------------------------------------------------- |
| **`PENDING`**   | **승인** | <mark style="color:red;">`ACTIVE`</mark> 전환 → 로그인 가능            |
| **`PENDING`**   | **거절** | 확인 팝업 → <mark style="color:red;">`REJECTED`</mark> 전환           |
| **`ACTIVE`**    | **잠금** | 확인 팝업 → <mark style="color:red;">`SUSPENDED`</mark> 전환 (기본 30분) |
| **`SUSPENDED`** | **해제** | <mark style="color:red;">`ACTIVE`</mark> 복귀                     |
| **`REJECTED`**  | `—`    | 화면에서 되돌리는 버튼 없음                                                 |

## <mark style="color:blue;">역할 (ADMIN / USER)</mark>

***

| 역할          | 권한                                          |
| ----------- | ------------------------------------------- |
| **`ADMIN`** | 인스턴스 승인·API 키 발급, 계정 승인·잠금, 고객사 등록·삭제 포함 전체 |
| **`USER`**  | 조회 중심 (대시보드·인스턴스·이벤트·고객사) + 본인 비밀번호 변경      |

{% hint style="danger" %}
**이 화면에서 역할(ADMIN ↔ USER)을 바꾸는 기능은 없습니다.** 권한 변경이 필요하면 연구소팀에 요청하십시오 ([17. 에스컬레이션](../part-4/17.-escalation.md)).
{% endhint %}

## <mark style="color:blue;">자주 받는 내부 문의</mark>

***

| 문의                        | 확인                                                              |
| ------------------------- | --------------------------------------------------------------- |
| **"가입했는데 로그인이 안 돼요"**     | 상태가 <mark style="color:red;">`PENDING`</mark>인지 → 승인            |
| **"로그인하니 계정 잠금이라고 나와요"**  | 상태가 <mark style="color:red;">`SUSPENDED`</mark>인지 → 해제          |
| **"승인 거절이라고 나와요"**        | 상태가 <mark style="color:red;">`REJECTED`</mark> — 재가입 또는 연구소팀 문의 |
| **"비밀번호를 잊었어요"**          | **화면에 초기화 기능 없음** → 연구소팀 요청                                     |
| **"관리자 메뉴가 안 열려요 (403)"** | 역할이 <mark style="color:red;">`USER`</mark> — 권한 변경은 연구소팀 요청     |
