# 8. 사용자 (ADMIN)

`/admin-users` — **우리 팀 운영자 계정**을 승인·관리하는 화면입니다. 고객사 계정이 아니라 **Poseidon Ops에 로그인하는 내부 계정**입니다.

부제: *사용자 승인 / 거절 / 잠금 / 해제*

{% hint style="danger" %}
**ADMIN 전용입니다.** USER에게도 사이드바 메뉴는 보이지만 클릭하면 **403 화면**으로 넘어갑니다.
{% endhint %}

자동 갱신이 없습니다. `새로고침` 버튼을 쓰고, 승인·잠금 등 작업 후에는 자동으로 다시 조회됩니다.

## 화면 구성

```
┌──────────────────────────────────────────────────────────────────────┐
│ 사용자                                              [⟳ 새로고침]      │
├──────────────────────────────────────────────────────────────────────┤
│ ⏱ 1명의 사용자가 가입 승인 대기 중입니다             [검토하기 →]       │
│   신규 가입 요청을 검토하고 승인 또는 거절해 주세요.                     │
├───────────────┬───────────────┬───────────────┬──────────────────────┤
│ 👥 전체 7     │ ✓ 활성 5 71.4%│ ⏱ 대기 1 14.3%│ 🔒 잠금/거절 1 14.3% │
├───────────────┴───────────────┴───────────────┴──────────────────────┤
│ 🔍 아이디, 이름, 이메일 검색                                           │
├────┬────────┬──────┬─────────────────┬──────────────┬────────┬───────┤
│No. │ 아이디  │ 이름 │ 이메일           │ 전화번호      │ 상태    │ 작업  │
│ 1  │ newcs  │ 김지원│ cs2@mono.co.kr  │010-1234-5678 │PENDING │승인 거절│

└────┴────────┴──────┴─────────────────┴──────────────┴────────┴───────┘
```

### 승인 대기 배너

`PENDING`이 1건 이상일 때만 나타납니다. `검토하기 →`를 누르면 **PENDING만 필터링**됩니다.

### 상단 4칸 — 클릭하면 필터

| 칸 | 대상 |
| --- | --- |
| **전체 사용자** | 필터 해제 |
| **활성 (ACTIVE)** | 정상 사용 중인 계정 |
| **대기 (PENDING)** | 가입 승인 대기 |
| **잠금 / 거절** | `SUSPENDED` + `REJECTED` |

### 테이블 열

| 열 | 내용 |
| --- | --- |
| **No.** | 화면상 순번 |
| **아이디** | 로그인 ID |
| **이름** | 가입 시 입력한 실명 |
| **이메일** | 가입 이메일 |
| **전화번호** | 가입 전화번호 |
| **상태** | `PENDING` / `ACTIVE` / `SUSPENDED` / `REJECTED` |
| **역할** | `ADMIN` / `USER` |
| **가입일** | 날짜 + 시각. 기본 **최신순 정렬** |
| **작업** | 상태에 따라 달라짐 (아래) |

검색은 **아이디 · 이름 · 이메일**을 대상으로 합니다.

## 계정 상태 4가지

| 상태 | 의미 | 로그인 |
| --- | --- | --- |
| `PENDING` | 가입했으나 승인 전 | ❌ (팝업 `승인 대기 중`) |
| `ACTIVE` | 정상 사용 중 | ✅ |
| `SUSPENDED` | 잠김 | ❌ (팝업 `계정 잠금`) |
| `REJECTED` | 가입 거절됨 | ❌ (팝업 `승인 거절`) |

## 상태별 작업 버튼

| 현재 상태 | 버튼 | 결과 |
| --- | --- | --- |
| `PENDING` | **승인** | `ACTIVE` 전환 → 로그인 가능 |
| `PENDING` | **거절** | 확인 팝업 → `REJECTED` 전환 |
| `ACTIVE` | **잠금** | 확인 팝업 → `SUSPENDED` 전환 (**기본 30분**) |
| `SUSPENDED` | **해제** | `ACTIVE` 복귀 |
| `REJECTED` | `—` | 화면에서 되돌리는 버튼 없음 |

{% hint style="warning" %}
**`거절`은 화면에서 되돌릴 수 없습니다.** 실수로 거절했다면 본인이 다시 가입해야 하거나 개발팀 조치가 필요합니다. 애매하면 `PENDING`으로 두고 확인 후 처리하십시오.
{% endhint %}

{% hint style="info" %}
**잠금은 기본 30분**입니다. 그 전에 풀어야 하면 `해제`를 누르면 즉시 `ACTIVE`가 됩니다.
{% endhint %}

## 역할 (ADMIN / USER)

| 역할 | 권한 |
| --- | --- |
| `ADMIN` | 인스턴스 승인·API 키 발급, 계정 승인·잠금, 고객사 등록·삭제 포함 전체 |
| `USER` | 조회 중심 (대시보드·인스턴스·이벤트·고객사) + 본인 비밀번호 변경 |

{% hint style="danger" %}
**이 화면에서 역할(ADMIN ↔ USER)을 바꾸는 기능은 없습니다.** 권한 변경이 필요하면 개발팀에 요청하십시오 ([17. 에스컬레이션](../part-4/17.-escalation.md)).
{% endhint %}

## 자주 받는 내부 문의

| 문의 | 확인 |
| --- | --- |
| "가입했는데 로그인이 안 돼요" | 상태가 `PENDING`인지 → **승인** |
| "로그인하니 계정 잠금이라고 나와요" | 상태가 `SUSPENDED`인지 → **해제** |
| "승인 거절이라고 나와요" | 상태가 `REJECTED` — 재가입 또는 개발팀 문의 |
| "비밀번호를 잊었어요" | **화면에 초기화 기능 없음** → 개발팀 요청 |
| "관리자 메뉴가 안 열려요 (403)" | 역할이 `USER` — 권한 변경은 개발팀 요청 |
