# 8. 설정

`/settings` — 로그인한 **본인 계정의 비밀번호를 변경**하는 화면입니다. 시스템 설정이나 고객사 설정을 바꾸는 화면이 아닙니다.

## 비밀번호 변경

```
┌────────────────────────────────────────────────────────────┐
│ 설정                                                        │
│ 계정 보안 설정                                                │
├────────────────────────────────────────────────────────────┤
│ 🔒 비밀번호 변경                                    csmain   │
│                                                            │
│  현재 비밀번호  [ ●●●●●●●● ]                                 │
│  새 비밀번호    [ ●●●●●●●● ]     새 비밀번호 확인 [ ●●●●●●●● ]  │
│                                                            │
│                                    [ 비밀번호 변경 ]         │
└────────────────────────────────────────────────────────────┘
```

| 입력 항목       | 규칙                     |
| ----------- | ---------------------- |
| **현재 비밀번호** | 필수. 틀리면 변경이 거부됩니다      |
| **새 비밀번호**  | 필수, **8자 이상**          |
| **새 비밀번호 확인** | 새 비밀번호와 일치해야 함         |

* 오른쪽 위에 현재 로그인한 계정 아이디가 표시됩니다.
* 입력값은 **암호화되어 전송**됩니다.
* 변경에 성공하면 입력 칸이 비워지고 성공 메시지가 표시됩니다.

{% hint style="info" %}
비밀번호를 **잊어버린 경우**에는 이 화면을 쓸 수 없습니다(현재 비밀번호가 필요). 관리자에게 요청해 [7. 사용자 관리](7.-users.md) 화면에서 처리하거나, 개발팀에 초기화를 요청해야 합니다.
{% endhint %}

## 이 화면에서 할 수 없는 것

| 하고 싶은 것            | 실제 위치                                                          |
| ------------------ | -------------------------------------------------------------- |
| 고객사 인증 키(API Key) 발급 | [5. 인스턴스 관리](5.-instances.md)                                  |
| 고객사 정보·이메일 변경      | [6. 테넌트 관리](6.-tenants.md)                                     |
| 다른 사용자 계정 관리       | [7. 사용자 관리](7.-users.md) (ADMIN 전용)                            |
| 알림 임계값·수신 채널 변경    | 화면에 없음 — 서버 설정 사항이므로 개발팀 요청                                    |
| 하트비트 주기·장애 판정 시간 변경 | 화면에 없음 — 고객사 설정(주기) 또는 서버 설정(판정 기준). [10. 상태 판정 기준](../part-3/10.-status.md) 참조 |

{% hint style="warning" %}
Poseidon 화면에는 **고객사 Odyssey 설정을 원격으로 바꾸는 기능이 없습니다.** 고객사 설정(주소·인증 키·하트비트 주기 등)은 고객사가 자기 서버의 `config/system.yml` 을 수정하고 재시작해야 반영됩니다. 고객에게 "저희가 원격으로 바꿔드릴 수 있다"고 안내하면 안 됩니다.
{% endhint %}
