# 5. 이벤트

<mark style="color:red;">**`/events`**</mark> — **최근 고객사에서 일어난 일**을 한 줄씩 시간순으로 보는 화면. "**언제부터 이랬나", "어제 밤에 무슨 일이 있었나**"를 확인하는 곳입니다.

<div data-with-frame="true"><figure><img src="../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>

## <mark style="color:blue;">상단 KPI 3개</mark>

***

| KPI           | 의미                                                             |
| ------------- | -------------------------------------------------------------- |
| **전체 이벤트**    | 조회된 전체 건수                                                      |
| **에러 수신**     | <mark style="color:red;">`ERROR_RECEIVED`</mark> 건수 + 전체 대비 비율 |
| **하트비트 타임아웃** | <mark style="color:red;">`HEARTBEAT_TIMEOUT`</mark> 건수 + 비율    |

{% hint style="info" %}
**하트비트 타임아웃 비율이 갑자기 오르면 우리 쪽 또는 네트워크 문제일 가능성**이 있습니다. 특정 고객사에 몰려 있는지, 여러 고객사에 흩어져 있는지 좌측 **`고객사`** 필터로 확인하십시오. 여러 고객사에 동시 발생이면 즉시 에스컬레이션 대상입니다.
{% endhint %}

## <mark style="color:blue;">이벤트 타입 5가지</mark>

***

| 화면 표시         | 내부 값                                                | 기본 심각도       | 언제                     |
| ------------- | --------------------------------------------------- | ------------ | ---------------------- |
| **서비스 시작**    | <mark style="color:red;">`STARTED`</mark>           | **INFO**     | 엔진이 기동 신호를 보냈을 때       |
| **서비스 종료**    | <mark style="color:red;">`SHUTDOWN`</mark>          | **WARN**     | **정상 종료** 신호를 보냈을 때    |
| **하트비트 타임아웃** | <mark style="color:red;">`HEARTBEAT_TIMEOUT`</mark> | **CRITICAL** | 180초 미수신으로 **DOWN** 전환 |
| **에러 수신**     | <mark style="color:red;">`ERROR_RECEIVED`</mark>    | **ERROR**    | Cypher가 예외를 보고했을 때     |
| **복구**        | <mark style="color:red;">`RECOVERED`</mark>         | **INFO**     | 끊겼다가 다시 신호가 온 경우       |

## <mark style="color:blue;">좌측 필터</mark>

***

| 필터         | 동작                                                                                                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **검색**     | 고객사명, 요약, 상세 내용을 검색                                                                                                                                                          |
| **이벤트 타입** | 5종 + `전체`. 각 항목에 **건수가 함께 표시**되어 분포를 바로 볼 수 있음                                                                                                                               |
| **심각도**    | <mark style="color:red;">`CRITICAL`</mark> <mark style="color:red;">`ERROR`</mark> <mark style="color:red;">`WARN`</mark> <mark style="color:red;">`INFO`</mark> — 다시 누르면 해제 |
| **고객사**    | 이벤트가 많은 고객사 순. 각 고객사별 건수 표시                                                                                                                                                  |

## <mark style="color:blue;">이벤트 한 줄 읽는 법</mark>

***

| 위치           | 내용                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **왼쪽 점·아이콘** | 심각도 색 + 이벤트 타입 아이콘                                                                                                                                           |
| **굵은 글씨**    | 이벤트 요약 (없으면 타입 이름)                                                                                                                                           |
| 이벤트 타입       | 이벤트 타입 코드 (<mark style="color:red;">`HEARTBEAT_TIMEOUT`</mark> 등)                                                                                            |
| **그 아래**     | 상세 내용                                                                                                                                                        |
| **🏢**       | 고객사명                                                                                                                                                         |
| **오른쪽 위**    | 상대 시간 (<mark style="color:red;">`3분 전`</mark>)                                                                                                               |
| **오른쪽 아래**   | 절대 시각 — 오늘이면 <mark style="color:red;">`14:21:03`</mark>, 어제면 <mark style="color:red;">`어제 14:21`</mark>, 그 전이면 <mark style="color:red;">`07-28 14:21`</mark> |

## <mark style="color:blue;">이 화면 활용 패턴</mark>

***

| 상황                   | 어떻게                                                                                    |
| -------------------- | -------------------------------------------------------------------------------------- |
| **"어제 밤 몇 시부터 끊겼나"** | 고객사 필터 → 타입 <mark style="color:red;">`하트비트 타임아웃`</mark> → 절대 시각 확인                     |
| **"정상 종료였나 장애였나"**   | 해당 시각 근처에 <mark style="color:red;">`서비스 종료`</mark>가 있으면 정상 종료                          |
| **"복구는 됐나"**         | 타입 <mark style="color:red;">`복구`</mark> 또는 <mark style="color:red;">`서비스 시작`</mark> 확인 |
| **"이 고객사만 문제인가"**    | 고객사 필터 해제 후 같은 시간대에 다른 고객사도 있는지 확인                                                     |
| **"에러가 몰린 고객사는"**    | 타입 <mark style="color:red;">`에러 수신`</mark> → 좌측 고객사 목록의 건수 비교                          |
