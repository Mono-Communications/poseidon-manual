## <mark style="color:blue;">고객사가 보내는 신호 4가지</mark>

***

| 시점          | 신호               | 화면에 반영되는 곳                                                                                      |
| ----------- | ---------------- | ----------------------------------------------------------------------------------------------- |
| **기동 시 1회** | **기동 등록**        | 인스턴스 목록에 나타남 + 이벤트 <mark style="color:red;">`서비스 시작`</mark>                                     |
| **30초마다**   | **하트비트** (지표 동봉) | 상태 <mark style="color:red;">`UP`</mark> 유지, <mark style="color:red;">`하트비트`</mark> 열 갱신, 지표 그래프 |
| **종료 시 1회** | **종료 알림**        | 이벤트 <mark style="color:red;">`서비스 종료`</mark> — 계획된 종료로 기록, 장애 알림 아님                             |
| **오류 발생 시** | **오류 보고**        | 인스턴스 상세 <mark style="color:red;">`에러`</mark> 탭 + 이벤트 <mark style="color:red;">`에러 수신`</mark>    |

## <mark style="color:blue;">흐름</mark>

***

```
1) 고객사가 엔진 기동
      │
      ├─► 기동 등록 ──► Gateway 인증 ──► DB 등록
      │                                 └─► 인스턴스 화면에 등장 (UP)
      │                                     이벤트: 서비스 시작
2) 이후 30초마다
      ├─► 하트비트 + 지표 ──► 하트비트 시각 갱신
      │                       
      │
3) ERROR/FATAL 로그 발생 시
      ├─► 오류 보고 ──► 오류 저장 + 이벤트 생성 ──► 알림 발송
      │                                           └─► 인스턴스 상세 '에러' 탭
      │
4) 3분 넘게 하트비트가 안 오면
      └─► 서버가 자체 판단으로 DOWN 처리 + 장애 알림
                                          └─► 이벤트: 하트비트 타임아웃
```

## <mark style="color:blue;">고객이 자주 묻는 것과 답</mark>

***

| 질문                      | 답                                                   |
| ----------------------- | --------------------------------------------------- |
| **"저희 서버에 들어오는 건가요?"**  | 아닙니다. 고객사 → Poseidon **단방향**입니다. 인바운드 개방이 필요 없습니다   |
| **"원격으로 제어하나요?"**       | 명령을 내리는 기능이 없습니다. 받기만 합니다                           |
| **"발송 데이터가 나가나요?"**     | 집계 수치와 예외 정보만 나갑니다. 수신번호·메시지 본문·DB 레코드는 전송 항목에 없습니다 |
| **"우리 DB에 접근하나요?"**     | 접근하지 않습니다. 엔진이 이미 가진 지표를 요약해 보내는 것뿐입니다              |
| **"실시간인가요?"**           | 30초 주기입니다. 장애 인지에는 최대 3\~4분이 걸립니다                   |
| **"연동이 끊기면 발송이 멈추나요?"** | 멈추지 않습니다. 지표·감시만 중단됩니다                              |
