# 1. 접속과 계정

### 접속 주소

| 구분   | 주소                              |
| ---- | ------------------------------- |
| 대시보드 | `http://4.217.193.23/dashboard` |
| 로그인  | `http://4.217.193.23/login`     |
| 회원가입 | `http://4.217.193.23/signup`    |

로그인하지 않은 상태로 어떤 주소에 접근하든 자동으로 로그인 화면으로 이동합니다.

### 계정 만들기

1. **회원가입** 화면에서 아래 항목을 입력합니다.

| 항목      | 규칙             |
| ------- | -------------- |
| 아이디     | 4\~20자, 영문·숫자만 |
| 비밀번호    | 8자 이상          |
| 비밀번호 확인 | 위와 동일해야 함      |
| 이메일     | 이메일 형식         |
| 전화번호    | 숫자와 하이픈(-)만    |

2. 가입 직후에는 **PENDING(승인 대기)** 상태이며 로그인할 수 없습니다.
3. **관리자(ADMIN)가 [사용자 관리](../part-2/7.-users.md) 화면에서 승인**해야 사용할 수 있습니다.

{% hint style="info" %}
신규 팀원이 들어오면 ① 본인이 회원가입 → ② 관리자에게 승인 요청, 두 단계가 필요합니다. "가입했는데 로그인이 안 된다"는 문의는 승인 여부를 먼저 확인하십시오.
{% endhint %}

### 권한 (역할)

| 역할        | 화면 표시         | 할 수 있는 일                                                 |
| --------- | ------------- | -------------------------------------------------------- |
| **ADMIN** | Administrator | 모든 화면 + **사용자 승인**, **인스턴스 승인·거절·API Key 발급**, 활성/비활성 전환 |
| **USER**  | Operator      | 대시보드·모니터링 조회, 인스턴스 목록 조회, 테넌트 조회·등록, 본인 비밀번호 변경          |

* 사이드바의 **사용자 관리** 메뉴는 ADMIN에게만 보입니다.
* 인스턴스 관리 화면의 **액션 열(승인·거절·비활성화)** 도 ADMIN에게만 보입니다.
* 현재 로그인한 계정의 권한은 사이드바 왼쪽 아래에 `Administrator` / `Operator` 로 표시됩니다.

### 로그인 후 동작

* 로그인하면 자동으로 **대시보드**로 이동합니다.
* 로그인 정보(토큰)는 브라우저에 저장되어 창을 닫았다 열어도 로그인 상태가 유지됩니다.
* 토큰이 만료되면 자동으로 갱신되고, 갱신까지 실패하면 로그인 화면으로 돌아갑니다.
* 로그아웃은 사이드바 왼쪽 아래 사용자 영역의 **나가기 아이콘**을 누릅니다.

### 비밀번호

* 비밀번호는 화면에서 **암호화되어 전송**됩니다.
* 변경은 [8. 설정](../part-2/8.-settings.md) 화면에서 합니다 (현재 비밀번호 필요, 새 비밀번호 8자 이상).
* 로그인 실패가 반복되면 계정이 잠길 수 있습니다. 잠긴 계정은 관리자가 [7. 사용자 관리](../part-2/7.-users.md)에서 **해제**합니다 (기본 잠금 30분).

{% hint style="warning" %}
Poseidon 화면 계정은 **우리 내부 운영자 계정**입니다. 고객사에 계정을 만들어 주거나 화면 주소를 공유하지 마십시오. 고객에게 전달하는 것은 Odyssey 설정값(주소·인증 키)과 고객용 매뉴얼입니다.
{% endhint %}
