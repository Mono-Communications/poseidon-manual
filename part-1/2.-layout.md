# 2. 화면 구조 한눈에 보기

로그인하면 아래 구조가 나옵니다. 왼쪽 사이드바로 이동하고, 가운데에서 작업합니다.

```
┌──────────────┬──────────────────────────────────────────────────────┐
│  Poseidon    │ 대시보드          ●30초마다 자동 갱신  🔔  🌙  ⬤ 홍길동 ▾│ ← 상단바
├──────────────┼──────────────────────────────────────────────────────┤
│ 관제          │ [대시보드 ×] [A고객사 - odyssey-1 ×]                    │ ← 탭 바
│ ▸ 대시보드     ├──────────────────────────────────────────────────────┤
│ ▸ 인스턴스     │                                                      │
│ ▸ 이벤트       │                                                      │
│              │                     콘텐츠 영역                        │
│ 관리          │              (선택한 메뉴의 화면)                       │
│ ▸ 고객사       │                                                      │
│ ▸ 인스턴스 관리 │  ← ADMIN 전용 (USER는 클릭 시 403)                     │
│ ▸ 사용자       │  ← ADMIN 전용 (USER는 클릭 시 403)                     │
│              │                                                      │
│ 내 계정        │                                                      │
│ ▸ 설정        │                                                      │
├──────────────┤                                                      │
│ ▸ 접기        │                                                      │
└──────────────┴──────────────────────────────────────────────────────┘
```

### 메뉴 구성 (사이드바)

메뉴는 **3개 그룹 7개 항목**입니다.

| 그룹 | 메뉴 | 주소 | 용도 | 권한 |
| --- | --- | --- | --- | --- |
| **관제** | **대시보드** | `/dashboard` | 전체 현황 요약 | 전체 |
| | **인스턴스** | `/instances` | 실시간 상태 목록 → 상세 진입 | 전체 |
| | **이벤트** | `/events` | 최근 7일 기동·종료·오류 이력 | 전체 |
| **관리** | **고객사** | `/tenants` | 고객사 등록·조회 → 상세 진입 | 조회 전체 / 등록·삭제 **ADMIN** |
| | **인스턴스 관리** | `/admin-instances` | 승인·거절·해지, **API 키 발급** | **ADMIN 전용** |
| | **사용자** | `/admin-users` | 운영자 계정 승인·거절·잠금·해제 | **ADMIN 전용** |
| **내 계정** | **설정** | `/settings` | 내 정보, 비밀번호 변경 | 전체 |

{% hint style="danger" %}
**`인스턴스`(관제)와 `인스턴스 관리`(관리)는 완전히 다른 화면입니다.**

* **인스턴스** = 지금 살아있는지 보는 곳 (`UP` / `DOWN`)
* **인스턴스 관리** = 등록 절차를 처리하는 곳 (`PENDING` / `APPROVED` / `REVOKED`, API 키 발급)

문의 응대 시 이 둘을 섞으면 답이 틀어집니다.
{% endhint %}

사이드바 맨 아래 **접기** 버튼으로 아이콘만 남기고 폭을 줄일 수 있습니다.

### 메뉴에 없는 화면 2개

목록에서 **행을 클릭**해야 열리는 화면이 두 개 있습니다. 사이드바에는 나오지 않습니다.

| 화면 | 여는 방법 | 주소 |
| --- | --- | --- |
| **인스턴스 상세** | 인스턴스 목록에서 행 클릭 (또는 대시보드에서 인스턴스 칩·이벤트 클릭) | `/instances-detail?id=…` |
| **고객사 상세** | 고객사 목록에서 행 클릭 (또는 카드 클릭) | `/tenants-detail?id=…` |

### 상단바

| 요소 | 의미 |
| --- | --- |
| 왼쪽 제목 | 현재 보고 있는 화면 이름 |
| `● 30초마다 자동 갱신` | **표시만 되는 안내 버튼입니다. 비활성 상태라 눌러도 동작하지 않습니다.** 실제 갱신 주기는 각 화면 안의 선택기로 바꿉니다 |
| 🔔 알림 아이콘 | **아직 동작하지 않습니다** ([9. 설정](../part-2/9.-settings.md) 알림 = 준비 중) |
| 🌙 / ☀ | 다크 모드 ↔ 라이트 모드 전환 |
| 사용자 영역 | 아바타·이름·역할 표시. 클릭하면 **로그아웃** |

### 탭 바

**인스턴스 상세**와 **고객사 상세**는 열 때마다 상단에 **탭으로 쌓입니다**. 여러 고객사를 비교할 때 유용합니다.

| 탭 | 라벨 형식 |
| --- | --- |
| 인스턴스 상세 | `고객사명(공백 제거 8자) - 인스턴스명` |
| 고객사 상세 | `고객사명` |

탭에서 **마우스 오른쪽 클릭**하면 `닫기 / 다른 탭 닫기 / 왼쪽 탭 닫기 / 오른쪽 탭 닫기 / 모두 닫기 / 탭 고정`을 쓸 수 있습니다.

### 자동 갱신 — 화면마다 다릅니다

자동 갱신이 있는 화면에는 **우측 상단에 주기 선택기**(`30초 / 1분 / 5분 / OFF`)와 새로고침 버튼이 있습니다.

| 화면 | 자동 갱신 | 기본 주기 |
| --- | --- | --- |
| 대시보드 | 있음 | **30초** |
| 인스턴스 (목록) | 있음 | **30초** |
| 이벤트 | 있음 | **1분** |
| 인스턴스 상세 | 있음 | **1분** |
| 고객사 / 고객사 상세 | **없음** | — (`새로고침` 버튼) |
| 인스턴스 관리 / 사용자 | **없음** | — (`새로고침` 버튼, 작업 후 자동 재조회) |
| 설정 | 없음 | — |

{% hint style="info" %}
**브라우저 탭을 다른 탭으로 옮기면 자동 갱신이 멈춥니다.** 다시 돌아오면 즉시 한 번 갱신한 뒤 재개됩니다. 오래 방치했다 돌아온 화면의 숫자는 이미 최신입니다.
{% endhint %}

### 화면에서 자주 보는 상태 값 — 3종류를 구분하십시오

성격이 전혀 다른 "상태"가 세 종류 나옵니다. **헷갈리면 고객 응대가 틀어집니다.**

| 구분 | 나오는 화면 | 값 | 의미 |
| --- | --- | --- | --- |
| **엔진 상태** | 대시보드, 인스턴스, 인스턴스 상세 | `UP` / `DOWN` | 고객사 엔진이 **살아있는지** (하트비트 기준) |
| **등록 상태** | 인스턴스 관리, 고객사 상세 | `PENDING` / `APPROVED` / `REJECTED` / `REVOKED` | API 키 **발급·승인 절차상의 단계** |
| **계정 상태** | 사용자 | `PENDING` / `ACTIVE` / `SUSPENDED` / `REJECTED` | 우리 팀 **운영자 계정** 상태 |

색은 다음과 같이 읽습니다.

| 색 | 엔진 상태 | 등록 상태 | 계정 상태 |
| --- | --- | --- | --- |
| 초록 | `UP` | `APPROVED` | `ACTIVE` |
| 주황 | — | `PENDING` | `PENDING` |
| 빨강 | `DOWN` | `REJECTED` | `REJECTED`, `SUSPENDED` |
| 회색 | — | `REVOKED` | 그 외 |

{% hint style="warning" %}
`APPROVED`(등록 승인 완료)와 `UP`(엔진 가동 중)은 전혀 다른 뜻입니다. **키는 승인됐지만 고객사가 아직 엔진을 안 켰거나 방화벽이 막혀 있으면**, 인스턴스 관리에서는 `APPROVED`인데 인스턴스 화면에는 아예 안 뜨거나 `DOWN`으로 보입니다.
{% endhint %}

### 서비스 타입 칩

인스턴스가 어떤 제품인지 색 칩으로 구분합니다. 전 화면 공통입니다.

| 칩 | 색 | 제품 |
| --- | --- | --- |
| `ODYSSEY` | 파랑 | 발송 엔진 |
| `TWOWAY` | 보라 | 수신(양방향) 엔진 |
| `CS` | 청록 | 데스크톱 메시징 클라이언트 |
| `M2X` | 갈색 | 레거시 (Cypher 사이드카로 감시) |

### 시각 표기

| 표기 | 의미 |
| --- | --- |
| `12초 전`, `5분 전`, `3시간 전`, `2일 전` | 상대 시간 (하트비트·이벤트 발생 등) |
| `14:23:07` | **오늘** 발생 |
| `어제 14:23` | 어제 발생 |
| `07-28 14:23` | 그 이전 |
| `2026. 07. 30. 14:23` | 절대 시각 (에러 상세의 발생 시각 등) |
| `-` | 값 없음 (한 번도 수신되지 않음) |
