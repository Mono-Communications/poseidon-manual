# 2. 화면 구조 한눈에 보기

로그인하면 아래 구조의 화면이 나옵니다. 왼쪽 사이드바로 메뉴를 이동하고, 가운데 영역에서 실제 작업을 합니다.

```
┌──────────────┬──────────────────────────────────────────────────┐
│ 🔱 POSEIDON   │  POSEIDON / 대시보드          ● LIVE   14:23:07  │ ← 상단 바
│ Command Center├──────────────────────────────────────────────────┤
│              │                                                  │
│ ▸ 대시보드     │                                                  │
│ ▸ Odyssey     │                                                  │
│   모니터링      │              콘텐츠 영역                          │
│ ▸ 인스턴스     │         (선택한 메뉴의 화면이 표시됨)               │
│ ▸ 테넌트       │                                                  │
│ ▸ 사용자 관리   │  ← ADMIN 계정에만 보임                            │
│ ▸ 설정        │                                                  │
│              │                                                  │
├──────────────┤                                                  │
│ 👤 사용자명    │                                                  │
│   Operator  ⇥ │  ← 로그아웃 버튼                                   │
└──────────────┴──────────────────────────────────────────────────┘
```

### 메뉴 구성

| 메뉴                 | 주소            | 용도                                     | 권한       |
| ------------------ | ------------- | -------------------------------------- | -------- |
| **대시보드**           | `/dashboard`  | 전체 인스턴스 요약(전체/실행 중/중지됨) + 현황 표         | 전체       |
| **Odyssey 모니터링**   | `/monitoring` | 인스턴스 상태 목록, 상세 진입(오류 로그 확인)            | 전체       |
| **인스턴스**           | `/instances`  | API Key 발급·승인, 인스턴스 활성/비활성 관리          | 조회 전체 / 액션 ADMIN |
| **테넌트**            | `/tenants`    | 고객사 등록·조회, 고객사별 인스턴스 확인                | 전체       |
| **사용자 관리**         | `/users`      | 운영자 계정 승인·거절·잠금·해제                     | **ADMIN 전용** |
| **설정**             | `/settings`   | 본인 비밀번호 변경                             | 전체       |

### 상단 바

| 요소             | 의미                                     |
| -------------- | -------------------------------------- |
| `POSEIDON / …` | 현재 보고 있는 화면 이름                         |
| ● **LIVE**     | 화면이 실시간 갱신 모드로 동작 중임을 나타내는 표시          |
| `14:23:07`     | 현재 시각 (초 단위로 갱신)                       |

### 자동 갱신되는 화면 / 안 되는 화면

{% hint style="info" %}
**대시보드와 Odyssey 모니터링 목록은 30초마다 자동으로 다시 조회**됩니다. 그 외 화면(인스턴스 상세, 인스턴스 관리, 테넌트, 사용자 관리)은 **화면에 들어간 시점의 데이터**이므로, 최신 상태를 보려면 브라우저를 새로고침하거나 목록으로 나갔다 다시 들어가야 합니다.
{% endhint %}

| 화면            | 자동 갱신     |
| ------------- | --------- |
| 대시보드          | 30초마다     |
| Odyssey 모니터링 목록 | 30초마다     |
| 인스턴스 상세(오류 로그) | 없음 (진입 시 1회) |
| 인스턴스 관리       | 없음 (액션 후 자동 재조회) |
| 테넌트 / 사용자 관리  | 없음        |

### 화면에서 자주 보는 상태 값

Poseidon 화면에는 **성격이 다른 두 종류의 "상태"** 가 나옵니다. 헷갈리면 고객 응대가 틀어지므로 반드시 구분하십시오.

| 구분        | 표시되는 화면                | 값                                          | 의미                       |
| --------- | ---------------------- | ------------------------------------------ | ------------------------ |
| **엔진 상태** | 대시보드, Odyssey 모니터링     | `UP` / `DOWN` / `UNKNOWN`                  | 고객사 Odyssey가 **살아있는지**   |
| **등록 상태** | 인스턴스 관리, 테넌트 상세        | `PENDING` / `APPROVED` / `REJECTED` / `REVOKED` | API Key **발급·승인 절차상의 단계** |
| 계정 상태     | 사용자 관리                 | `PENDING` / `ACTIVE` / `REJECTED` 등        | 우리 팀 **운영자 계정** 상태       |

색상은 다음과 같이 읽습니다.

| 색      | 엔진 상태     | 등록 상태            | 계정 상태            |
| ------ | --------- | ---------------- | ---------------- |
| 초록(성공) | `UP`      | `APPROVED`       | `ACTIVE`         |
| 주황(주의) | —         | `PENDING`        | `PENDING`        |
| 빨강(위험) | `DOWN`    | `REJECTED`       | `REJECTED`, `SUSPENDED` |
| 회색(기타) | `UNKNOWN` | `REVOKED`        | 그 외              |

{% hint style="warning" %}
`APPROVED`(등록 승인 완료)와 `UP`(엔진 가동 중)은 전혀 다른 뜻입니다. **API Key는 승인됐지만 고객사가 아직 Odyssey를 안 켰거나 방화벽이 막혀 있으면**, 인스턴스 관리 화면에서는 `APPROVED`인데 모니터링 화면에는 아예 안 뜨거나 `DOWN`으로 보입니다.
{% endhint %}

### 시각 표기

| 표기               | 의미                                    |
| ---------------- | ------------------------------------- |
| `12초 전`, `5분 전`  | 마지막 하트비트 등 상대 시간                      |
| `2026. 07. 30. 14:23` | 등록일·발생 시각 등 절대 시간                     |
| `-`              | 값이 없음 (한 번도 수신되지 않음)                  |
